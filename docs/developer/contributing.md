# Contribuir — Guía práctica 🤝

**Resumen:** Cómo preparar cambios, ramas y PRs correctamente.

- Usa ramas con prefijos `feature/`, `fix/`, `chore/`.
- Añade tests y actualiza `/docs/` si introduces cambios que afecten al usuario.
- Ejecuta `pre-commit` y `python manage.py verify_urls` antes de commitear.
- Documenta el cambio en `/docs/` y en el PR.

Gracias por contribuir — toda mejora es bienvenida.
